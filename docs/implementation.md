# 实现说明

2026-10-22：将已在 https://hqyx.website/rubiks-cube/ 上线的交互重构同步回原仓库。原提交历史保留；由早期单 HTML 改为以下模块。

- `model.js`：贴纸身份、位置与法向量、精确四分之一转、公式解析、真实轴旋转轨迹与平面投影、松手归位规则。
- `session.js`：成组操作、撤销重做与分支、历史检查点、存档一致性校验。
- `views.js`：Three.js 三维、SVG 圆形轨道与展开图，使用共同状态和连续角度。
- `cube.js`：指针状态机、候选方向锁定、视角控制、多层选择、历史播放、独立公式示例与持久化。
- `theme.js`、`cube.css` 与根目录 `style.css`：沿用博客主题。

圆形图不是任意摆放的装饰圆。每个贴纸有唯一点位，围绕 X／Y／Z 的空间圆轨迹投影成平面椭圆；同一几何轨迹可被多个贴纸和逻辑层共享。默认展示所有轨迹，当前操作加亮。位于转轴上的贴纸为固定点，不虚构圆轨迹。三阶有 54 点，七阶有 294 点。

网站部署版使用站内博客导航和共用根资源。本仓库版本仅将博客导航改为线上域名，并将共用样式／图标／字体路径改为可随仓库静态托管的相对路径；魔方模型、视图和控制器保持一致。

自动化测试覆盖全部阶数、轴、连续范围及逆操作，圆点唯一性与轨迹中间位置，公式校验、历史分支／成组打乱、损坏存档和检查点。上线前另完成真实浏览器的连续拖动、取消、公式恢复、响应式与触摸模拟验证；未声称完成实体手机测试。

博客分类管理属于博客后端，保留在博客项目；本仓库提供魔方实现和在线入口，不复制文章、评论、账号、SQLite 或上传资源。

2026-10-22 后续交互修订：公式播放器增加「重新播放」，从独立保存的起点重播，不重复累加已演示步骤；退出前等待当前动画和播放器任务结束，再恢复完整原局与视图、设置、多层选择及上一步提示。简单模式修正纵向相机转向。松手规则改为优先90°，半圈需明确拖到160°，速度不再额外推进至半圈。三维区下方常驻上一步操作提示，覆盖普通用户拖动、按钮转动、撤销／重做和打乱，并保存到本机。回归测试增加相机方向、操作描述和90°优先边界；浏览器验收覆盖播放中重播／退出、完整原局恢复、普通用户转动提示及存档恢复。

学习目录扩展：`catalog.js`负责阶数、阶段、分组与查找，`curriculum.js`负责阶段讲解、模型生成的局面图、逐步解释和独立示例构造。完整三阶库包含41 F2L、57 OLL、21 PLL、Cross指导和原有资料；四阶13个示例覆盖中心／合棱／降阶CFOP／两类特例。共171条资料、169条可播放。`FORMULAS.md`记录GAN参考图的角色、具体算法核对来源、编号／配色差异及记号边界。

`2R`解析为第二单层，`Rw`解析为右侧双层；四阶拒绝M／E／S歧义记号。逐步解释基于实际展开动作，公式起点经24种整块朝向的中心配色校对，使典型局面与图示拿法一致。“回到第一步”暂停在起点，自动重播单独保留；显式应用检查相同阶数。新增测试检验完整数量、全部算法正逆、57 OLL唯一朝向与F2L不变、41 F2L保留十字及其他槽、PLL顶色、四阶特例中心和翼棱配对。

倍速／沉浸／观察扩展：`formulaRate`作为独立本机偏好，只接受0.25、0.5、0.75、1、1.25、1.5。公式动画逐帧累计时间乘以当前倍速，动态切换不跳转角度；普通转层不使用该倍速。仍尊重关闭自动动画和减少动画设置。

双视图使用相同绘图尺寸，三维投影适配最短边；右侧不会再因左侧控制区和播放器拉长。沉浸模式请求documentElement原生全屏，提供双／左／右三种显示范围，失败时使用全视口布局；右侧独立模式移动同一组控制节点，退出后还原，状态和播放器均不重建。内容可滚动，退出入口固定；Esc与原生fullscreenchange同步退出。

演示中的鼠标／触摸手势只调整观察视角或二维取景；播放中可旋转、滚轮缩放、双指旋转／捏合和二维平移，第二指不会取消公式动作。退出仍恢复原局的相机与取景。浏览器验证覆盖六档实际时长、倍速保存、原生全屏与fallback、三种显示范围、右侧独立控制，以及观察过程中公式终态和步骤不变。

`targets.js`按贴纸身份归组物理块，为每条公式固定目标。F2L锁定前右槽的一角一棱，三维目标色面双框与圆形目标贴纸双圈、展开图双框共同跟随连续角度；不改变贴纸颜色。播放器展示目标色名、槽位与稳定步骤的归位数量，OLL按朝向判断；四阶特例只聚焦翼棱。完成后保留、退出清除，前后步骤与重播不重选目标。显式应用沿用示例预期终点，不能因动作播放完就虚报任意原局已复原。新增测试遍历169个算法的目标完整性与终点，验证41种F2L五枚贴纸归属于两个正确物理块，以及不匹配局面不会假报到位。

最新交互修订取消简单／进阶选择，统一使用2～7阶、内层／连续多层与自由相机。旧存档仅忽略原mode限制，完整会话与相机仍按原方式恢复；保存modeadvanced标记供旧版兼容。操作面板汇集原面按钮和层范围，折叠时隐藏手动控制、保留上一操作与计时；`controlsCollapsed`单独记住。

`timer.js`提供可测试的单调时钟状态机，暂停时间不累加，结束冻结、明确重新开始才清零。保存时记录累计毫秒和状态，刷新恢复为暂停；独立公式示例自动暂停本局计时，退出后手动继续。新开局有时间记录时也需确认，确认后清零。全屏右侧模式移动整个practicePanel，避免复制计时或丢失折叠状态。
